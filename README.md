\# AutoCallManager 📱



\*\*An Android call management application built with Kotlin and Jetpack Compose.\*\*



AutoCallManager combines SIM-based calling workflows, contact management, Google Sheets integration, call analytics, and local call history in one Android application.



\## ✨ Features



\- 📞 SIM-based calling workflow

\- 📋 Contact management and calling queue controls

\- 📊 Call analytics dashboard

\- 🔗 Google Sheets integration for contact retrieval and call activity updates

\- 🕘 Local history of recent call attempts

\- 🔐 Google OAuth 2.0 authentication

\- ⏸️ Calling queue and break-duration controls

\- 📦 Signed APK for Android device testing



\## 🛠️ Tech Stack



\- Kotlin

\- Jetpack Compose

\- Android SDK

\- Google Sheets API

\- Google OAuth 2.0

\- Gradle



\## ⚙️ Google Sheets Configuration



To use the spreadsheet features:



1\. Configure a Google Cloud project and enable the Google Sheets API.

2\. Set up the appropriate OAuth consent screen and Android OAuth client.

3\. Configure the application's spreadsheet ID and worksheet name.

4\. Authorize the Google account used by the application.

5\. Ensure that account has the required spreadsheet permissions.



OAuth testing restrictions and Google verification requirements may apply depending on how the application is distributed.



\## 🚀 Build and Run



1\. Clone this repository.

2\. Open the project in Android Studio.

3\. Configure the Android SDK and required build environment.

4\. Sync the Gradle project.

5\. Build and run the application on a compatible Android device.



\## 🔒 Security



\- Never commit signing keys, passwords, OAuth tokens, or private credentials.

\- Keep local configuration and signing files outside version control.

\- Do not use real customer contact data in public examples.

\- Grant spreadsheet access only to authorized accounts.
